# 🩺 CareFlow AI

### AI-Powered Healthcare Support Prototype

CareFlow AI is an AI-assisted healthcare support prototype designed to help users understand and organize common health concerns through a simple, interactive web experience.

> **Important:** CareFlow AI is an educational prototype. It does not diagnose medical conditions, prescribe medication, or replace professional medical advice.

---

## ✨ Features

### 🩺 AI Health Assistant
Interactive conversational flows that collect basic information such as symptom severity and duration before providing general educational guidance.

### 📝 Symptom Summary
Helps organize a user's reported concern into a structured summary containing information such as the main concern, duration, severity, and other symptoms.

### 📚 Healthcare FAQ
Provides simple answers to common healthcare-related questions and explains the limitations of AI-based healthcare support.

### 📅 Appointment Request
Allows users to prepare basic appointment information before contacting a healthcare professional.

### 🛡️ Safety Guidance
The application includes safety-oriented messaging and encourages users to seek appropriate professional care when symptoms may be severe or urgent.

## 🧠 Prototype Architecture

The current assessment prototype uses a controlled response layer for the interactive demonstration.

This approach allows the project to demonstrate:

- Conversational interaction
- Follow-up questions
- Healthcare safety behavior
- Feature workflows
- Prompt-engineered response design

without depending on external API availability during the demonstration.

---

## 🔐 Healthcare Safety

CareFlow AI should not be used as a replacement for professional medical care.

The prototype does not:

- Diagnose medical conditions
- Prescribe medication
- Replace healthcare professionals
- Provide emergency treatment

Users experiencing severe, sudden, or potentially urgent symptoms should seek appropriate medical or emergency assistance.
